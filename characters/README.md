# Original office characters

12 original characters, licensed under the repository's MIT license. No branded
mascots are used. `manifest.json` describes the assets; `hepsi.png` is the overview
and `butce.md` records the measured size budget.

Each state is a horizontal PNG strip: `n` frames, each `w × h` pixels (currently
36 × 34). The manifest supplies the frame rate, foot anchor (`anker.x/y`) and
recommended scale (`olcek_onerisi`, currently 2). Render with
`image-rendering: pixelated`. EVREN has a separate `walk_sol` strip so its chest
emblem keeps its orientation. Only Pofu has a `run` strip; the other characters
play `walk` at 1.5 times its frame rate.

identify the software being represented, without implying endorsement.

`hooks/char-data.ts` is generated by `tools/char_data_uret.py` from the manifest
and these PNG strips (Python with Pillow):

```sh
python -I tools/char_data_uret.py piksel-ofis/hooks/char-data.ts
```

Inputs resolve relative to the script; the output path is the command argument.
The generator measures opaque bounds in idle frame 0 (alpha ≥ 128, exclusive
right/bottom) and preserves each horizontal anchor, including Pofu's x=14. The
render anchor y is the smaller of the manifest anchor and the opaque bottom:
34 for all characters except EVREN (33). This keeps its transparent bottom row
below the feet. The manifest's original anchor remains unchanged.

Assets live here at repository root so both language editions can share one
source. Generating the Turkish edition does not alter the English edition.
